# WanderSphere AI 🌍✈️

WanderSphere AI is a modern travel platform designed to revolutionize the way you plan and experience your journeys. It combines breathtaking design with intelligent trip planning to make every vacation unforgettable.

## 🚀 Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **AI Integration**: Antigravity (Google DeepMind)
- **Language**: TypeScript

## ✨ Core Feature: Multi-City Road Trip

The standout feature of WanderSphere AI is our **Multi-City Road Trip** planner. Instead of traditional point-to-point travel, this feature allows users to seamlessly plan complex itineraries across multiple destinations. It intuitively handles routing, accommodations, and activities for each leg of your journey, ensuring a smooth and optimized travel experience.

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
